# TC-FYN-07 · Foto direkt med kameran

| | |
|---|---|
| **Område** | Nytt fynd och foton |
| **Prioritet** | Hög |
| **Typ** | 🖐️ Manuell |
| **Krav** | [SPEC.md avsnitt 4.3–4.5](../../SPEC.md) |

## Förutsättningar

- Inloggad i appen med ditt Jaktvind-konto
- Riktig iPhone

## Steg

| # | Gör så här | Förväntat resultat |
|---|---|---|
| 1 | Tryck **Nytt fynd** → **Ta eller välj foto** → **Ta bild** | Kameran öppnas |
| 2 | Fota en svamp och tryck **Använd bild** | Förhandsbild visas, rätt vriden, under 250 kB |
| 3 | Spara och öppna popupen | Fotot visas rätt vriden |

> Kameran och HEIC-formatet finns bara på riktig telefon.
