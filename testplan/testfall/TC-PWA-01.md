# TC-PWA-01 · Installera på hemskärmen

| | |
|---|---|
| **Område** | Installation och uppdatering |
| **Prioritet** | Hög |
| **Typ** | 🖐️ Manuell |
| **Krav** | [SPEC.md avsnitt 4.7, 8](../../SPEC.md) |

## Förutsättningar

- Riktig iPhone, Safari

## Steg

| # | Gör så här | Förväntat resultat |
|---|---|---|
| 1 | Öppna https://dennishoglund.github.io/svampkartan/ i Safari | – |
| 2 | Tryck **Dela** → **Lägg till på hemskärmen** → **Lägg till** | Ikonen (brun kartnål med kantarell på gul botten) hamnar på hemskärmen med namnet *Svampkartan* |
| 3 | Öppna appen från hemskärmen | Appen öppnas i helskärm utan Safaris adressfält |

> Kräver riktig iPhone.
